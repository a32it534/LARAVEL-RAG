# 🤖 LARAVEL-RAG

### سیستم چت هوشمند با استفاده از اسناد و هوش مصنوعی

**LARAVEL-RAG** یک برنامه هوشمند است که به شما اجازه می‌دهد فایل‌های خود را داخل سیستم قرار دهید و سپس درباره محتوای آن‌ها از هوش مصنوعی سؤال بپرسید.

این پروژه با **Laravel 12** و **GapGPT** ساخته شده و از روش **RAG** برای پیدا کردن اطلاعات مرتبط داخل اسناد استفاده می‌کند.

---

## ✨ امکانات

* 🤖 چت با هوش مصنوعی
* 📄 آپلود و پردازش فایل
* 🔎 جستجو در محتوای اسناد
* 🧠 استفاده از Embedding برای جستجوی معنایی
* 📚 پاسخ‌دهی بر اساس محتوای اسناد
* 💬 نمایش تاریخچه گفتگو
* 🇮🇷 پشتیبانی از زبان فارسی و RTL
* 📱 طراحی Responsive

---

## 🧠 RAG چیست؟

RAG باعث می‌شود هوش مصنوعی قبل از پاسخ دادن، ابتدا اطلاعات مرتبط را از فایل‌های شما پیدا کند.

برای مثال:

```text
📄 فایل شما
      ↓
✂️ تقسیم متن به قسمت‌های کوچک
      ↓
🧠 تبدیل متن به Embedding
      ↓
🗄 ذخیره در دیتابیس
```

وقتی کاربر سؤال می‌پرسد:

```text
❓ سؤال کاربر
      ↓
🧠 پیدا کردن اطلاعات مرتبط
      ↓
📚 پیدا کردن بخش مناسب از فایل
      ↓
🤖 ارسال اطلاعات به GapGPT
      ↓
💬 نمایش پاسخ
```

بنابراین پاسخ هوش مصنوعی بر اساس اطلاعات موجود در فایل‌های شما تولید می‌شود.

# 🏗 ساختار پروژه

در این پروژه بخش‌های اصلی به شکل زیر هستند:

### `RagController`

مدیریت درخواست‌های کاربر، آپلود فایل و ارسال سؤال به سیستم.

### `DocumentParserService`

خواندن فایل و تبدیل محتوای آن به متن.

### `VectorSearchService`

پیدا کردن قسمت‌های مرتبط با سؤال کاربر.

### `GapGptService`

ارتباط با API سرویس GapGPT برای تولید پاسخ و انجام Embedding.

### `Document`

اطلاعات مربوط به فایل‌های آپلود شده را نگهداری می‌کند.

### `DocumentChunk`

قسمت‌های کوچک‌شده متن و Embedding آن‌ها را نگهداری می‌کند.

# 🚀 نصب پروژه

ابتدا پروژه را دریافت کنید:

```bash
git clone https://github.com/a32it534/LARAVEL-RAG.git
```

و وارد پوشه پروژه شوید:

```bash
cd LARAVEL-RAG
```

نصب وابستگی‌های Laravel:

```bash
composer install
```

نصب وابستگی‌های Frontend:

```bash
npm install
```

ساخت فایل `.env`:

```bash
cp .env.example .env
```

در ویندوز CMD:

```cmd
copy .env.example .env
```

ساخت کلید Laravel:

```bash
php artisan key:generate
```

اجرای Migration:

```bash
php artisan migrate
```

ساخت فایل‌های Frontend:

```bash
npm run build
```

اجرای پروژه:

```bash
php artisan serve
```

سپس وارد آدرس زیر شوید:

```text
http://127.0.0.1:8000
```

# ⚙️ تنظیم GapGPT

در فایل `.env` اطلاعات API را وارد کنید:

```env
GAPGPT_API_KEY=your_api_key_here

GAPGPT_BASE_URL=https://api.gapgpt.app/v1

GAPGPT_CHAT_MODEL=gpt-4o

GAPGPT_EMBEDDING_MODEL=text-embedding-3-large

FILESYSTEM_DISK=local
```

🔐 **نکته مهم:** فایل `.env` را در GitHub قرار ندهید و API Key خود را با دیگران به اشتراک نگذارید.

# 📄 نحوه کار برنامه

ابتدا کاربر یک فایل را آپلود می‌کند.

سیستم:

1. فایل را می‌خواند.
2. متن فایل را استخراج می‌کند.
3. متن را به قسمت‌های کوچک تقسیم می‌کند.
4. برای قسمت‌های متن Embedding ایجاد می‌کند.
5. اطلاعات را در دیتابیس ذخیره می‌کند.

بعد از آن، کاربر می‌تواند سؤال خود را بپرسد.

سیستم قسمت مرتبط فایل را پیدا می‌کند و آن را به **GapGPT** می‌دهد.

در نهایت GapGPT پاسخ را تولید می‌کند و پاسخ به کاربر نمایش داده می‌شود.
